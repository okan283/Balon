# Balon

Çizgi roman ekran görüntülerindeki konuşma balonlarını telefonda tarayıp çeviren kişisel okuyucu.

- **Tarama:** [Tesseract.js](https://github.com/naptha/tesseract.js), tarayıcının içinde, telefonda çalışır.
- **Çeviri:** [MyMemory](https://mymemory.translated.net/doc/spec.php) ücretsiz çeviri servisi. Servise sadece balon metinleri gönderilir.
- **Saklama:** Eklenen sayfalar ve çeviriler sadece o cihazın tarayıcısında (IndexedDB) tutulur. Bu depoda çizgi roman içeriği yoktur.

Kişisel kullanım içindir. Çevrilmiş sayfaları paylaşma.
